# Ліцей І-ІІІ ступенів №25 — лендінг

Односторінковий сайт ліцею №25 Шевченківського району м. Києва
(вул. Володимирська, 1 / Десятинна, 15).

Без збірки і фреймворків — чистий HTML, CSS і JavaScript.
Щоб подивитися локально, достатньо відкрити `index.html` у браузері.

## Структура

```
index.html            уся сторінка
css/styles.css        стилі, палітра та анімації
js/main.js            інтерактив (паралакс, слайдери, пошук, форма)
assets/               фото будівлі, логотип, портрет директора
assets/staff/         фото педагогів + README з конвенцією імен
docs/                 технічне завдання та список педагогів
```

## Як додати фото педагога

Покласти JPG у `assets/staff/` з іменем зі списку в
[assets/staff/README.md](assets/staff/README.md) — сайт підхопить його сам,
код правити не треба. Поки файлу немає, показуються ініціали.

## Форма заявки

За замовчуванням форма збирає дані в готовий лист і відкриває поштовий
клієнт на `25.kyiv.school@gmail.com`.

Щоб заявки приходили автоматично, без відкриття поштового клієнта:
зареєструвати безкоштовну форму на [formspree.io](https://formspree.io)
і вставити виданий рядок у `FORM_ENDPOINT` на початку `js/main.js`.

## Логотип

Емблема — inline SVG у символі `#i-shield` на початку `index.html`.
Обведена за фотографією тиснення `assets/IMG_9911.JPG`; якщо з'явиться
оригінальний вектор від дизайнера, замінюється в цьому одному місці —
далі він автоматично йде в шапку, футер і фавікон.

## Публікація

Сайт статичний, тож підходить будь-який хостинг. Для GitHub Pages:
Settings → Pages → Source: `Deploy from a branch` → гілка `main`, тека `/ (root)`.

Увага: на Linux-хостингах (зокрема GitHub Pages) регістр в іменах файлів
має значення — фото педагогів мають бути з розширенням `.jpg` маленькими
літерами.
