# Фото педагогів

Покладіть файли в цю теку — сайт підхопить їх автоматично, **правити код не потрібно**.
Поки файлу немає, на його місці показується кругла аватарка з ініціалами.

## Правила

- Формат: **JPG**, ім'я файлу — рівно як у списку нижче (маленькими латинськими літерами,
  розширення теж маленькими: `.jpg`, не `.JPG` — на хостингу регістр має значення).
- Пропорції: **вертикальні, 4:5** (як фото директора), мінімум 480×600 px. Обличчя у верхній третині.
  Портрет на повний зріст теж підійде — сайт обріже його сам.
- Вага: до ~300 КБ на файл.
